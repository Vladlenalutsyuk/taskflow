# TaskFlow — система управления задачами

Лабораторная работа №1 по дисциплине
«Разработка серверных приложений».

Вариант №9 — «Система управления задачами (Task Tracker / Kanban)».

## Назначение

TaskFlow — система для организации командной работы.
Руководитель создаёт доски и задачи, назначает исполнителей
и отслеживает выполнение. Исполнители изменяют статусы задач
и учитывают затраченное время.

## Основные возможности

- Создание досок задач.
- Добавление участников на доски.
- Создание задач и назначение исполнителей.
- Установка сроков выполнения.
- Перемещение задач между статусами.
- Учёт времени, затраченного на задачи.

## Роли пользователей

- Руководитель проекта.
- Исполнитель.
